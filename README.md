One line back to a younger self: stop rehearsing speeches for people who left, and learn one decent meal before the noodles win.

## The line

> Stop rehearsing the speech for people who already left. Learn one decent meal; future you is starving and sick of instant noodles.

## Run it

Node 22, standard library only, no network.

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
